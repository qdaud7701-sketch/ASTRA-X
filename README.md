# ASTRA-X: Astronaut Mission Trainer

A browser-based 3D Mars survival game made for the NASA International Space Apps Challenge 2026.

Explore Mars, find fuel cells, collect resources, craft tools, repair and drive a rover, and survive dust storms and meteors while managing oxygen, food, battery and health. Discovering items unlocks short knowledge files that explain the real science and NASA missions behind them.

## Controls
- Move: W A S D / arrow keys (joystick on phones)
- Look: drag mouse or finger
- Run: Shift, Jump: Space
- R: enter or leave rover, C: crafting, Q: scanner, K: knowledge library

## Built with
HTML, CSS, JavaScript and Three.js (WebGL). Terrain, rocks and textures are generated in code.
